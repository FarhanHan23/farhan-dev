# Kenapa Saya membuat blog di Astro js

Dalam membangun website personal dan blog teknikal, kecepatan, kesederhanaan, dan kontrol penuh atas konten adalah hal yang paling utama. 

Astro menawarkan arsitektur **Islands Architecture** dan prinsip *Zero-JS by default*, di mana halaman HTML dihasilkan secara statis di waktu build, sehingga performanya sangat cepat dan ramah SEO.

## Keunggulan Astro

1. **Zero-JS by Default**: Tidak ada JavaScript yang dikirim ke browser kecuali kita membutuhkannya.
2. **Content Collections**: Type-safe schema menggunakan Zod untuk memastikan struktur konten valid.
3. **Fleksibilitas Framework**: Bisa menggunakan komponen React, Vue, atau Svelte jika dibutuhkan.
